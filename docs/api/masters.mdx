The Masters API is the collection of ADMIN-only CRUD endpoints exposed by every module under `src/modules/masters/`. All routes require `Authorization: Bearer <token>` and a JWT with `role = ADMIN`. The controllers are guarded by `JwtAuthGuard` \+ `RolesGuard` and decorated `@Roles('ADMIN')` at the class level.

Because every master follows the same REST shape, this page documents the endpoint surface as a matrix rather than one section per resource. For each resource's DTO shape, foreign-key checks, and side effects, see the corresponding [Masters module page](/modules/masters).

## Standard endpoint shape

Unless the resource is called out in the [exceptions](#exceptions) section below, every master exposes:

| Method | Path | Purpose | Body |
| --- | --- | --- | --- |
| `GET` | `/<resource>` | List all rows | — |
| `GET` | `/<resource>/active` | List active rows (`is_active = true`) | — |
| `GET` | `/<resource>/:id` | Get one by primary key | — |
| `POST` | `/<resource>` | Create | `Create<Resource>Dto` |
| `PATCH` | `/<resource>/:id` | Partial update | `Update<Resource>Dto` = `PartialType(Create<Resource>Dto)` |
| `DELETE` | `/<resource>/:id` | Delete by primary key | — |

All responses are JSON. Validation errors return `400 Bad Request` with a `class-validator` message array. Missing rows return `404 Not Found`. Duplicate unique keys (e.g. duplicate `username`, `email`, `vehicle_number`, `(brand, color)` tray-type) return `409 Conflict` from the corresponding service.

## Exceptions

### Client categories

`client-categories` uses composite-key routing because the underlying `master_client_category` row has a composite primary key of `(client_id, category)` and no other columns to update:

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/client-categories` | List all |
| `GET` | `/client-categories/client/:clientId` | List categories for one client |
| `POST` | `/client-categories` | Create |
| `DELETE` | `/client-categories/:clientId/:category` | Delete by composite key |

There is no `GET /client-categories/:id`, no `PATCH`, and no `/active` route.
