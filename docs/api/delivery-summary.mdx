The Delivery Summary API is a read-only rollup used by admins before finalizing a paper. It aggregates delivered quantities from `order_sheet_items` by `(distributor, category, brand, product_group)` and builds a grid keyed by billing group.

There are no write endpoints; the summary is derived from live data on every call.

---

## GET /delivery-summary/:paperId

### Purpose

Returns the billing group summary for the paper.

### Access control

`EMPLOYEE` (and above).

### Response

Returns HTTP **200** with:

<ResponseField name="summaries" type="array">
  One entry per `(distributor, category, brand, product_group)` slice, each containing:

  - `summaryKey` — the composite key
  - `distributorId`, `category` (`MILK`/`NON_MILK`), `brandId`, `brandName`, `productGroupId`, `productGroupName`
  - `columns` — the product columns for this slice
  - `rows` — one row per billing group with `groupId`, `groupName`, and one `product_<productId>` field per column holding the total delivered quantity for that billing group in that slice
</ResponseField>

### Behavior

- Reads all `order_sheet_items` with `delivered_qty > 0` on the paper.
- Groups by `(distributor, category, brand, product_group)` at the outer level and by billing group at the row level.
- Available in every paper state; used by admins as one input to the `finalize` decision.
