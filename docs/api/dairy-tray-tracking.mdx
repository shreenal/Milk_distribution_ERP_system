The Dairy Tray Tracking API is the depot-side counterpart to the client-side [Trays API](/api/trays). Rows are stored in `dairy_tray_transaction` under a single `dairy_tray_paper` per `order_paper` (uniqueness on `order_paper_id`). One row exists per `(dairy_tray_paper_id, vehicle_id, tray_type_id)`.

The controller is mounted at `@Controller('dairy-trays')` with `:paperId` as the leading path segment.

---

## GET /dairy-trays/:paperId

### Purpose

Returns the depot-level tray view for the paper: the `dairy_tray_paper` (if any) plus all `dairy_tray_transaction` rows, grouped for grid presentation.

### Access control

`EMPLOYEE` (and above).

### Response

Each transaction row includes `vehicle_id`, `tray_type_id`, `opening_balance`, `trays_taken`, `trays_returned`, and `closing_balance` (`opening_balance + trays_taken − trays_returned`).

---

## POST /dairy-trays/:paperId/save

### Purpose

Upserts depot tray rows for the paper. Operators enter only `returned` per `(vehicleId, trayTypeId)`. `opening_balance` (from the previous paper's closing balance) and `trays_taken` (from vehicle allocation for the paper's active session) are computed server-side.

### Access control

`EMPLOYEE`. Editable when `WorkflowStateService.canEditDairyTrayTracking(status)` returns true — that is, when the paper is in `NIGHT_SUBMITTED` or `REOPENED`.

### Request body

`SaveDairyTrayEntriesDto`:

<ParamField body="entries" type="array" required>
  Array of `{ vehicleId: number, trayTypeId: number, returned: number (>= 0) }`.
</ParamField>

#### Example request

```json
POST /dairy-trays/128/save
Authorization: Bearer <token>
Content-Type: application/json

{
  "entries": [
    { "vehicleId": 3, "trayTypeId": 2, "returned": 40 },
    { "vehicleId": 4, "trayTypeId": 2, "returned": 20 }
  ]
}
```

### Validation and errors

| Scenario | HTTP status | Detail |
| --- | --- | --- |
| Paper not in `NIGHT_SUBMITTED` or `REOPENED` | `400 Bad Request` | Locked in other states |
| `returned` negative | `400 Bad Request` | DTO validation |
| Unknown `vehicleId` or `trayTypeId` | `400 Bad Request` | Validation service rejects |
