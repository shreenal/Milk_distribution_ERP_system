The Trays API records the physical crate and tray movement between the distributor and each client. Every delivery leaves trays with the client, and every subsequent visit collects some back. The API tracks opening balance, expected trays taken (derived from delivered quantity via `product_tray_rule`), actual trays taken, and trays returned. Closing balance is computed server-side and carried forward as the next day's opening balance.

`EMPLOYEE` (and above) can read and write, subject to the paper's workflow state.

---

## GET /trays/sheet/:sheetId

### Purpose

Returns the tray view for the sheet: the `client_tray_transaction` rows one per `(client, tray_type)` along with any grid metadata built by `TraysService`.

### Response

Each row carries `client_id`, `tray_type_id`, `opening_balance`, `expected_trays_taken` (nullable), `trays_taken`, `trays_returned`, `closing_balance`, and `remarks`.

---

## POST /trays/sheet/:sheetId/save

### Purpose

Upserts tray transactions for the sheet. Operators enter only `returned` per `(clientId, trayTypeId)`. `opening_balance`, `trays_taken`, `expected_trays_taken`, and `closing_balance` are computed server-side.

### Access control

`EMPLOYEE`. Editable when `WorkflowStateService.canEditTrays(status)` returns true — that is, when the paper is in `NIGHT_SUBMITTED` or `REOPENED`.

### Behavior

- `opening_balance` = previous paper's `closing_balance` for the same `(client, tray_type)`.
- `expected_trays_taken` and `trays_taken` are derived from delivered quantities using `product_tray_rule` matched most-specific-first on `(product_group, brand, product_type, packaging_type)`.
- `closing_balance = opening_balance + trays_taken − trays_returned`.

### Request body

Direct array of `SaveTrayReturnDto`:

<ParamField body="returned" type="number" required>
  Non-negative integer. The only operator-entered field.
</ParamField>

#### Example request

```json
POST /trays/sheet/42/save
Authorization: Bearer <token>
Content-Type: application/json

[
  { "clientId": 101, "trayTypeId": 2, "returned": 3 },
  { "clientId": 102, "trayTypeId": 2, "returned": 1 }
]
```

### Validation and errors

| Scenario | HTTP status | Detail |
| --- | --- | --- |
| Paper not in `NIGHT_SUBMITTED` or `REOPENED` | `400 Bad Request` | Trays locked in other states |
| `returned` negative | `400 Bad Request` | DTO validation |
| Unknown `clientId` or `trayTypeId` | `400 Bad Request` | Validation service rejects |
