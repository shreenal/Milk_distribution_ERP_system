## Purpose

The Collections module records money received from clients during the night and morning routes. Each row is one `client_collection` keyed by `(sheet, client, category)` — a client that participates in both MILK and NON\_MILK gets two rows per sheet.

## Responsibilities

- Return the collection grid for a sheet (all client × category rows with amounts and remarks).
- Save employee-entered amounts for night save and morning save.
- Allow Admin to correct amounts and remarks after morning submit via a separate admin-save path.

## Business rules

- Night save (`canEditNightCollections`): allowed in `DRAFT`, `NIGHT_SUBMITTED`, and `REOPENED`. Writes only `office_amount_given`.
- Morning save (`canEditMorningCollections`): allowed in `NIGHT_SUBMITTED` and `REOPENED`. Writes `cash_collection`, `cheque_collection`, and `employee_remarks`.
- Admin save (`canAdminEditCollections`): allowed in `MORNING_SUBMITTED` and `REOPENED`. Writes `online_collection`, `bank_deposit`, and `admin_remarks`.
- One row per `(order_sheet_id, client_id, category)` — enforced by DB unique index.
- Employees write their own field set; Admins write only the admin fields listed above.

## Dependencies

- `PrismaService` — reads and writes `client_collection`.
- `WorkflowStateService` — status-gated writes.
- Master data — client and category resolution.

## Endpoints

| Method | Path | Role | Purpose |
| --- | --- | --- | --- |
| `GET` | `/collections/sheet/:sheetId` | EMPLOYEE | Return the collection grid |
| `POST` | `/collections/sheet/:sheetId/milk/night-save` | EMPLOYEE | Save night collections for MILK |
| `POST` | `/collections/sheet/:sheetId/non-milk/night-save` | EMPLOYEE | Save night collections for NON\_MILK |
| `POST` | `/collections/sheet/:sheetId/milk/morning-save` | EMPLOYEE | Save morning collections for MILK |
| `POST` | `/collections/sheet/:sheetId/non-milk/morning-save` | EMPLOYEE | Save morning collections for NON\_MILK |
| `POST` | `/collections/sheet/:sheetId/milk/admin-save` | ADMIN | Correct MILK admin fields after morning submit |
| `POST` | `/collections/sheet/:sheetId/non-milk/admin-save` | ADMIN | Correct NON\_MILK admin fields after morning submit |

## Request flow

```text
POST /collections/sheet/:id/{category}/{night,morning}-save
  → CollectionsController
  → CollectionsService.save{Night,Morning}Collections(sheetId, category, dto)
       for each client row:
         upsert client_collection keyed by (sheet, client, category)
```

## Database tables

- `client_collection` — see the [Data Model overview](/data-model/overview) for the schema.

## Lifecycle

```text
DRAFT         → POST /collections/.../night-save
NIGHT_SUB     → POST /collections/.../morning-save
MORNING_SUB   → POST /collections/.../admin-save (Admin only)
REOPENED      → any of the above (subject to role)
```
