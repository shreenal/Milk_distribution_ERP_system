This walks through starting the NestJS backend (`server/`) from a fresh clone. The Electron/Vite frontend under `client/` is out of scope for this page.

## Prerequisites

- **Node.js 20\+** (the project uses ESM and NestJS 11).
- **PostgreSQL** reachable via a `DATABASE_URL` connection string. The Prisma client is configured with the `@prisma/adapter-pg` driver-adapter (see `src/prisma/prisma.service.ts`).
- **npm** (or a compatible package manager).

## Environment variables

Create `server/.env` with:

```bash
DATABASE_URL=postgresql://user:password@localhost:5432/milk_erp
SECRET=change-me-to-a-long-random-string
PORT=3000
```

- `DATABASE_URL` — read by `PrismaService` (via `PrismaPg`) and by Prisma CLI.
- `SECRET` — signs and verifies JWTs. Read by `AuthModule` (`JwtModule.registerAsync`) and `JwtStrategy` through `ConfigService`.
- `PORT` — bound in `main.ts` (`process.env.PORT ?? 3000`).

`main.ts` also enables CORS for `http://localhost:5173` with `credentials: true` — this is the origin the Vite dev server uses.

## Get started

<Steps>
  <Step title="Install dependencies">
    ```bash
    cd server
    npm install
    ```
  </Step>
  <Step title="Generate the Prisma client">
    The client is emitted into `src/generated/prisma/` — every service and repository imports from there.

    ```bash
    npx prisma generate
    ```
  </Step>
  <Step title="Apply migrations">
    ```bash
    npx prisma migrate deploy
    ```

    Use `npx prisma migrate dev` while iterating on the schema.
  </Step>
  <Step title="Seed reference data (optional)">
    ```bash
    npx tsx prisma/seed.ts
    ```

    The seed creates the `ADMIN` and `EMPLOYEE` roles and a starting user. Adjust as needed before running against a real database.
  </Step>
  <Step title="Run the server">
    ```bash
    npm run start:dev
    ```

    The API is served at `http://localhost:3000`. Every route except `POST /auth/login` requires an `Authorization: Bearer <token>` header — see the [Auth API](/api/auth) to obtain a JWT.
  </Step>
</Steps>

## Verifying the install

Log in and hit `/auth/me`:

```bash
curl -X POST http://localhost:3000/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"your-seeded-password"}'

# then, with the accessToken from the response:
curl http://localhost:3000/auth/me \
  -H "Authorization: Bearer <accessToken>"
```

## Tests

Vitest is wired up. Only one repository spec ships today.

```bash
npm test              # single run
npm run test:watch    # watch mode
npm run test:cov      # coverage
```
